# On The Trail

One of my favourite projects is **On The Trail**, a watchOS application I built with **SwiftUI and HealthKit**.

The idea is simple: your real-world walking distance moves you along a virtual journey between cities.

I've built routes including:

* London → Paris
* Brussels → Luxembourg
* Tallinn → Riga
* Budapest → Zagreb
* Vilnius → Warsaw
* Lisbon → Madrid
* Berlin → Amsterdam
* Vienna → Rome

This project has been a great excuse to learn more about the Apple ecosystem, including:

* Swift & SwiftUI
* watchOS development
* HealthKit
* Persistent application state
* Codable & Hashable data models
* Tracking and calculating walking progress

It's also a good example of how I like to learn: **I had an idea for an app, and the idea gave me a reason to learn the technology.**

# I like making games

Game development has become one of my favourite ways to learn.

I've built and experimented with games across **Python, JavaScript, React, Kotlin and Swift**, and I'm particularly interested in the intersection of programming, systems design and game mechanics.

Some of the projects and ideas I've worked on include:

### Incremental Sheep Shearing

An incremental game about - unsurprisingly - shearing sheep.

I'm currently exploring ideas around progression, upgrades, automation and increasingly ridiculous amounts of wool.

Possible names have included **Baa Baa Boom**, **Shear Madness** and **Wool Rush**.

### Cooking Pachinko

A cooking game inspired by pachinko and Vampire Survivors-style progression.

You drop cooking equipment into a board and watch it bounce through ingredients, creating recipes and combos along the way.

The idea combines:

* Physics
* Randomised runs
* Recipe discovery
* Combos
* Power-ups
* Customer demands
* Progression

### Hangman Roguelite

A twist on traditional Hangman with roguelite progression. Very Slay the Spire-esque dungeon crawling (as I am low-key obsessed with Slay the Spire II)

The project uses:

**Frontend:** React + TypeScript
**Backend:** Flask + Python

Players can choose different character classes, each with their own abilities and play styles - including ideas such as a **Vowel Mage, Archivist, Berserker and Rogue**.

### Don't Push My Buttons

An Android game built with **Kotlin and Jetpack Compose**.

The game is built around a fixed collection of buttons and deliberately designed interactions rather than relying on procedurally generated visuals.

I've also experimented with **libGDX** and other approaches to Android game development.

# How I learn

I don't have a perfectly linear learning path.

I have an idea.

Then I realise I don't know how to build part of it.

So I learn it.

Then I discover something else I don't know.

So I learn that too.

That's taken me from teaching → Python → full-stack web development → AWS → Swift → watchOS → Kotlin → game development and plenty of rabbit holes in between.

**My projects are often my tutorials.**

I'm at my happiest when I'm building something, breaking it, figuring out why it broke, and eventually making it work.
